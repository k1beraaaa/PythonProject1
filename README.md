# Telegram-бот для записи клиентов

Бот принимает заявки в Telegram, показывает клиенту только свободное время, мгновенно уведомляет владельца и ведёт журнал заявок в Excel и Google Таблицах.

*English: a Telegram booking bot (aiogram 3) with free-slot selection, instant owner notifications and automatic logging to Excel / Google Sheets.*

## Демо-сценарий (30–60 секунд)

1. Клиент пишет боту «Записаться».
2. Бот спрашивает имя и услугу.
3. Клиент выбирает дату и свободное время кнопками. Занятые слоты не показываются.
4. Владельцу в Telegram сразу приходит готовая заявка.
5. Та же заявка появляется строкой в таблице (Excel и/или Google Таблицы).

## Возможности

- Диалог на конечном автомате (FSM): имя → услуга → дата → время
- Выбор даты и времени инлайн-кнопками, только свободные слоты
- Защита от двойной записи на одно время, в том числе при одновременных нажатиях
- Мгновенное уведомление владельца в Telegram
- Запись в Excel (`openpyxl`) и Google Таблицы (`gspread`) с автоматическим оформлением: шапка, чередование строк, фильтры, закреплённая первая строка
- Расписание настраивается через переменные окружения: часы работы, длина слота, выходные, горизонт записи

## Стек

Python 3.10+, [aiogram 3](https://docs.aiogram.dev/), openpyxl, gspread, python-dotenv

## Быстрый старт

```bash
git clone https://github.com/<ваш-логин>/telegram-booking-bot.git
cd telegram-booking-bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp settings.env.example settings.env
# впишите BOT_TOKEN (получить у @BotFather)

python main.py
```

Чтобы владелец получал заявки, напишите боту `/myid`, скопируйте число в `OWNER_CHAT_ID` в `settings.env` и перезапустите бота.

## Настройки (`settings.env`)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather | обязательно |
| `OWNER_CHAT_ID` | Chat ID владельца (узнать командой `/myid`) | `0` |
| `SERVICES` | Список услуг через запятую | Стрижка,Маникюр,Консультация |
| `WORK_START` / `WORK_END` | Начало и конец рабочего дня, часы | 10 / 19 |
| `SLOT_MINUTES` | Длина слота в минутах | 60 |
| `DAYS_AHEAD` | На сколько дней вперёд можно записаться | 7 |
| `DAYS_OFF` | Выходные (0 = понедельник, 6 = воскресенье) | 6 |
| `EXCEL_PATH` | Путь к файлу Excel | zayavki.xlsx |
| `GSHEET_ID` | ID Google Таблицы (необязательно) | не задан |
| `GOOGLE_CREDS` | Файл ключа сервисного аккаунта | service_account.json |

## Подключение Google Таблиц (необязательно)

1. В [Google Cloud Console](https://console.cloud.google.com) создайте проект и включите **Google Sheets API**.
2. Создайте сервисный аккаунт и скачайте JSON-ключ. Сохраните его как `service_account.json` рядом с `main.py`.
3. Создайте пустую Google Таблицу и дайте доступ «Редактор» адресу `client_email` из ключа.
4. Впишите ID таблицы (часть ссылки между `/d/` и `/edit`) в `GSHEET_ID`.

Если Google недоступен, заявка всё равно сохранится в Excel и уйдёт владельцу.

## Структура

```
main.py                 # весь бот
requirements.txt
settings.env.example    # пример настроек
bookings.json           # занятые слоты (создаётся автоматически)
zayavki.xlsx            # журнал заявок (создаётся автоматически)
```

Чтобы освободить слот, удалите соответствующую строку из `bookings.json`.

## Безопасность

Токен бота, `settings.env` и `service_account.json` не должны попадать в репозиторий, они перечислены в `.gitignore`.
